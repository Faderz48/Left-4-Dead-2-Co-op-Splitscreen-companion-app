Campaigns, models, weapons, sounds, and most gameplay add-ons should continue to load normally.

Old split-screen HUDs and main-menu replacements can conflict. Disable them temporarily if either view is clipped or missing.

For two Xbox controllers, start with Steam Input disabled. On Linux, enable its standard Gamepad layout only if direct input does not expose Player 2.
